## Conflict design methods

### The four-fold conflict escalation

Lay conflict layers in this order: person vs self → person vs nature → person vs person → person vs world.

### Bottom-layer conflict builds the world

Build the worldview from the most fundamental, most irreconcilable conflict. Ensure the core hook doesn't drift, or mid-run subscriptions drop.

### The three motive sources

| Source | Operation |
|---------|------|
| World background | the setting forces the protagonist to grow (e.g. demon chaos → no power, no survival) |
| The cheat | cheat mechanics create interest-driven motives (e.g. slaying demons gains power) |
| Character relationships | friends/family incidents create emotional motives (e.g. bullied/killed → revenge/rescue) |

### Motive-change transitions

- After a crisis resolves, immediately use supporting characters/antagonists to emphasize "only stronger power survives," transitioning naturally to the next stage
- Life-death crises don't fit every genre — adjust the difficulty intensity to the genre boundary
- When the previous crisis resolves, the next crisis's foreshadowing must be planted

### Conflict-source classification

Pick by genre:

| Source | Scenes |
|------|----------|
| Resources/interests | universal |
| Factions/races | fantasy, xianxia |
| Supernatural paths | mystery-supernatural genres |
| Faith/religion | western fantasy, historical |
| Church-state struggles | medieval, scheming |
| Ideals/values | all genres |

## Structure methods

### Climax back-derivation

Back-derive the main-line structure step by step:

1. Fix the one-sentence ending first
2. Back-derive tiered goals (world richest <-- continent <-- nation <-- province <-- city <-- county <-- town <-- village <-- family)
3. Split the big main line into mid main lines, mid into small; keep refining
4. After a small line completes, the mid line becomes the new small line; loop forward

### Main line = conflict-driven

The main-line story = solving a conflict. Split the big conflict into small conflicts to form storylines. Every stage must have one unsolvable core conflict.

### Sub-lines = means to complete the main line

Organize sub-lines by this logic: making money (main) → how to make it (sub) → with what (cheat confirmation). Sub-lines must eventually converge into the main line.

### The dual-line structure

#### Visible line & hidden line

- **Visible line**: the protagonist's line (actions and growth the reader sees directly)
- **Hidden line**: the antagonist's line / hidden-element line (purpose: connecting, setting up, nesting later plots)
- The hidden line must intersect the visible line late in the story, forming the volume climax

#### The four-quadrant structure

| | Visible line | Hidden line |
|--|------|------|
| **Main line** | protagonist ability upgrades + core plot advancement | antagonist covert actions / hidden-information line |
| **Sub-line** | resource line, connection line, status line | supporting-character hidden lines |

**Highest ROI structure**: the visible line has main + sub ("two carrying one"), the hidden line only has main.

At the climax: the hidden line fuses with the visible line; sub-lines merge into the main line or pause.

### The A-B interweaving method for progression fiction

| Line | Definition | Content |
|------|------|------|
| A line (upgrade line) | power upgrades | stat points, skills, equipment |
| B line (plot line) | conflict | pull conflict → get dragged in → burst → solve → gain |

Interweaving rhythm:
```
get strong -> pull conflict -> get strong -> dragged in -> get strong -> trigger conflict -> get strong -> solve -> gain -> get strong -> pull conflict...
```

**Core principle**: keep the protagonist slightly ahead in each skirmish; each small skirmish ends in a protagonist win; the big victory comes last.

Immersion enrichment:
1. In the A line: detail controllable resources, connections, equipment
2. In the B line: insert worldview, environment, emotion, character interaction; label antagonists/supporting characters

## Conflict design

### Gate-setting to stretch the plot

Use gates to split the main line into stage mini-lines, each with a clear driver:

| Gate type | Operation |
|----------|---------|
| System gates | first upgrade free; second needs resources; later split into normal/over tiers |
| Goal gates | entering the top academy needs vitality score + kill count + tournament ranking, one by one |
| Collection gates | breaking through a realm needs collecting multiple items, sought one by one |
| Consumption gates | when resources overflow, raise gates to consume them |

### The three-driver back-derivation

| Driver | Operation |
|--------|---------|
| Drama | design unexpected gains, lucky accidents |
| Conflict | design unavoidable conflicts/disasters |
| Desire/fear | use wanting something / fearing loss |

**Steps**: fix the protagonist's stage growth first (cheat upgrade/power boost/CP affinity/treasures/big-shot connections/money/status), then try all three drivers on each growth to back-design the plot.

Advantage: never stuck, always fresh.

### Conflict design points

#### The conflict core standard

- Conflicts must escalate: words → actions → fierce confrontation → deciding the outcome
- Conflicts must have clear results
- Essence: "someone blocks the protagonist from getting what they want"

#### Conflict vs contradiction

- "Contradiction" is level-1 structure (book/volume level); "conflict" is level-2 structure (concrete scene level)
- Contradiction decides the main-line direction; conflict is the concrete expression

#### The act-one trap

While solving the first conflict, the protagonist plants foreshadowing for the next conflict's burst. Function: natural plot dovetailing.

#### The over-gain technique

Over-gain is the universal technique: it can be later foreshadowing, setup, or a plot hook; its appearance is itself a payoff.

Classic pattern: the boss drops three things — 1. usable right now 2. giftable for relationships 3. unusable for now but clearly impressive.

### The eight redemption-conflict methods

| Method | Operation |
|---------|------|
| Redemption-goal conflict | redemption comes from the other's sacrifice; the trauma-maker is the other's closest kin |
| Redemption-action conflict | redemption sustained by lies; must hurt the other to complete self-redemption |
| Triangle | redemption causes a third party to need redemption |
| Redemption countdown | must complete before something happens, or fall into the abyss |
| Rising redemption cost | the payment keeps growing |
| Scarce redemption resources | resources suffice for one redemption only |
| Stance opposition | stance differs but each needs the other's help |
| Personality contrast | optimism vs pessimism, cold-blooded vs compassionate |

## Confrontation design

### Press the momentum, not the person

The antagonist doesn't target the protagonist personally but plans against a region/class/group, objectively trapping the protagonist.

Steps:
1. Give the antagonist their own goal (e.g. suppress cultivators in a region)
2. Put the protagonist inside the suppressed environment
3. After the protagonist overthrows the antagonist, the bottom stays numb
4. The bottom may exploit the protagonist's kindness for gains → new conflict

Advantage: the conflict has a logical foundation and is sustainable.

### The antagonist POV & info-gap technique

#### Function

Switch POV to the antagonist's scheming, creating "the reader knows, the protagonist doesn't" info gaps: deepen the antagonist persona, raise anticipation, make readers wait for the antagonist's comeuppance.

#### Writing

- No riddles — write the antagonist's plan openly
- Info gap = letting the reader know part of the information early, creating anticipation

Hidden-line rules see the dual-line structure above.

### Protagonist agency design

Design protagonist actions from three dimensions:

| Dimension | Meaning | Example |
|------|------|------|
| Do what others dare not | defy authority, challenge the strong | cutting down a superior |
| Do what others cannot | survive death, exceed limits | surviving a certain-death situation |
| Do what others never thought of | lucky accidents, roundabout wins | using a sausage recipe to fill a collection |

Drama shows agency; persona is the reason for action. No persona collapse for surprises.

## Romance-line design

### Career-line / romance-line coordination

First judge: what do the readers drawn in by the title and blurb want to see?

| Mode | Design focus | Readers want |
|------|---------|---------|
| Career-line main | cheat display and upgrades; the love interest is a reward | the protagonist getting stronger |
| Romance-line main | relationship changes; plot designed around the other's persona | CP interaction |

### The romance four stages

Advance the romance line in this order:

| Stage | Core | Key operation |
|------|----------|---------|
| Passing acquaintance | first meeting, first impression | use differing evaluations for tension |
| Romantic comedy | forced/accidental frequent contact | the testing stage is the core, 30-50% of the plot |
| Love across mountains | external pressure / identity truth / misunderstanding separates them | intensity high; persona changes based on the original persona |
| Finale | overcome the biggest obstacle | no new conflicts; only sugar |

#### Writing the testing stage

The testing stage is the romance core: two people testing and pulling without confirming feelings. Every test must read both "sweet" and "sour."

#### The persona-change hedging method

After the romance-line climax, the relationship upgrades: **both sides change**, and the change **inverts** their previous correspondence. Persona changes are partial, based on the original — never invented new personas.

## Cheat & identity

### Opening & entry point design (dual identity, dual cheat)

| Element | Design requirements |
|------|---------|
| Visible identity (social) | the public label = occupation + state. Must keep changing |
| Hidden identity (origins) | a prince fallen to the mortal world, a transmigrator, etc. Linked to the book's core conflict |
| Visible cheat | system, second-chance memories, etc. Must be an ability set with new things each time |
| Hidden cheat = the protagonist's personality | what makes the protagonist different is the cheat. Mid-late payoff |

**Four-point unity**: social identity, origins, cheat, and personality must be highly unified.

### Cheat design points

#### The five qualification questions

Check item by item when designing the cheat:

1. Does it make the protagonist stand out? Can it keep helping overcome difficulties?
2. Does it connect with the world/setting, with contrast?
3. Could it steal the show? Can that be prevented?
4. When the protagonist's resources multiply a hundred or thousand times, can it still solve the main conflict?
5. Can it express ideas and themes while solving conflicts?

#### Fragmentation

Split complex cheat abilities into fragments fused into the plot. Before collection completes = long-term anticipation; each fragment collected must solve at least one conflict.

## Loops & payoffs

### Payoff layering & loop writing

#### Loop (nesting) design

core creative point → dig the core selling point → fix the main line → cheat derives alongside.

#### Parallel writing

Interleave plot B inside plot A's setup, plot C inside B's setup; setups and payoffs stay continuous.

#### Multi-layer payoffs

Stack payoffs by layer:

1. On-site audience shocked
2. Off-site audience shocked
3. Experts shocked seeing the technique
4. Side characters shocked again after the info gap closes

Payoff = protagonist flex + side-character cognitive change. Put attention on the side characters' before/after change.

### The core-hook three-way split

| Type | Running mode | Use |
|------|----------|------|
| Repeatable | runs in every level-1 structure | progression fiction, system fiction, copying-entertainment |
| Non-repeatable | runs through the book, bursts once at the top climax | comeback, mask-drop, forbidden love |
| Long-setup | runs as anticipation points throughout | mystery, revenge, puzzle-solving |

Rhythm: the first level-1 structure must run it once or complete the first setup. Multiple consecutive level-1 structures without running = readers quit.

Dual-line conception: lay two lines — one repeats the core hook, one doesn't — alternating.

### Genre loop cores

Fix the loop core by genre and keep its sustain condition intact:

| Genre | Loop core | Sustain condition |
|------|---------|----------|
| Grinding/low-position openings | the map (training ground / local bully / destroyer) | the map doesn't collapse |
| Immortality | social change | society keeps changing |
| Infinite game | dungeon & reality | dungeon-reality doesn't collapse |
| Road trip | human interaction | characters don't collapse |
| Invincible fiction | enemies | enemies don't collapse |
| Homestead/sign-in/hoarding | external environment destruction | external destruction continues |
| Wild-idea fiction | core selling point loop | core selling point doesn't drift |

**Warning**: the loop drifting from the core selling point = losing differentiation competitiveness.

## Motives & traps

### "Give the character a dream" motivation method

| Concept | Traits | Example |
|------|------|------|
| Motivation | external push, material-leaning | because poor → want a big house |
| Dream | internal drive, spiritual pursuit | want to be a great writer |

Operation: besides external oppression/interest drives, give the character a "dream." Two layers combined, the character naturally comes alive.

Character goals must match the persona — a menial disciple dreaming of saving the sect lacks credibility; the sect's holy maiden saving the sect is plausible.

### The trap-loop structure (extreme-path fiction)

```
trap (environmental pressure) -> action (running the cheat) -> turn (bigger trap) -> action (breaking out stronger)
```

Core: keep turning up the heat; the protagonist always actively solves problems. Pair with playing-pig-eating-tiger, emotion pulling, status flex/comeuppance.

Points: pressure with measure; the reader must feel the protagonist has a way out; later pressure must exceed earlier.

### Setting-derivation plot method

Core formula: **environment + characters = plot**

Steps:
1. Give the environment (time/place/situation)
2. Give the characters (identity/relationships/motives/weaknesses/dreams/past)
3. Each added setting point: play-role logical derivation
4. Filter the setting combination best fitting the core emotion

### The hook-main-line-core-payoff framework

#### Hook types

| Type | Traits | Opening writing |
|------|------|---------|
| Event hook | the title is the event | enter the event immediately |
| Cheat hook | spread through the book, more early, fewer late | first write the protagonist → trap → goal → cheat display → small results |
| Persona hook | persona directly affects the plot | the persona itself produces drama |

**Rule**: event hooks and cheat hooks write differently. Writing an event hook with the cheat method makes readers quit.

#### Hook → main-line grafting

After the event ends, **immediately graft** the protagonist's goal. The goal may also be set up during the event.

#### Core payoff = the payoff cut on the main line

A flex deviating from the main line is an off-target payoff, not the core payoff.

#### Gravitas-reaction rules

Gravitas rule: the protagonist's reaction to provocation should be proportional to their set power/experience. High-power characters react lightly, not with rage. Design reaction templates by power tier: high power → light touch / one-finger kill; low power → restrained charging. Reaction design when insulted:
- Poison point: furious, face red
- Non-poison: a slight smile — "he's nothing"
- Hysterical → unsatisfying; calm one-finger kill → satisfying

## Plot organization

### The info-delivery order system

| Type | Structure | Use |
|------|------|------|
| Straight plot | raise question → reveal answer | basic narration |
| Exploratory plot | raise question → honest clue → reveal answer | setup passages |
| Surprise plot | raise question → false clue → reveal answer | reversal passages |
| Surprise + reversal | raise question → false clue 1 → false clue 2 → reveal answer | climax passages |

Readers only care about information once it's a "question." Every event has at least one value change and advances the main line at least one step. Events without value changes = filler chapters.

### Protagonist life routes expanding the network

Fix the protagonist's daily activity route → introduce new characters at daily contact points → new characters carry their own networks → new story material.

### Steps & buffers

- Buffer = the distance between the protagonist and supporting characters from interests/events/emotion; the wooing of that distance produces payoff
- Split goals into stages (like qi-training/foundation/core-formation); not only big goals, small ones too
- Three plot-advancement modes: actively handling troubles that advance the goal / actively advancing the goal and hitting troubles / troubles finding you that advance the goal when solved

### Event-driven principle

- Prose chapters must be composed of events; event content share ≥ half
- Events are the chance for value change: without events, the protagonist and main line don't change
- Setting delivered via events, not narration dumping

### Setting-derived conflict

Priority:
1. **Fun before useful**: drama first
2. **Torn-down plots are drama**: teardown scenes with payoffs get used directly
3. **When not fun enough, set up to raise anticipation**

## Quality checklist

After conflict & structure design, verify:

- [ ] Conflicts escalate in four folds (self → nature → people → world)
- [ ] Bottom-layer conflict tightly bound to the worldview, no core-hook drift
- [ ] The protagonist has ≥2 of the three motive sources (world background / cheat / relationships)
- [ ] Main-line structure split via climax back-derivation into big/mid/small lines
- [ ] Conflicts keep escalating (words → actions → fierce confrontation → deciding outcome) with clear results
- [ ] Every stage has one unsolvable core conflict driving readers
- [ ] Sub-lines converge back into the main line
- [ ] Hidden lines (if any) intersect the visible line at the climax
- [ ] Romance line (if any) advances in four stages, the testing stage 30-50%
- [ ] Cheat passes the five qualification questions; abilities fragmented into the plot
- [ ] Visible identity / hidden identity / visible cheat / hidden cheat four-point unity
- [ ] Core hook runs once or completes its first setup in the first level-1 structure
- [ ] Loop core matches the genre; no core-selling-point drift
- [ ] Every event has ≥1 value change and advances the main line
- [ ] Info-delivery order matches the scene type (basic/setup/reversal/climax)
- [ ] Motive transitions natural (previous crisis resolved plants the next crisis's foreshadowing)

agent prompt, and reference must use these English terms; the legacy Chinese terms

## House style notes

- 章节 `Chapter N` 标题与文件名使用阿拉伯数字（`chapter_001_*.md`、`## Chapter 1: …`）。
- 数字与计量：长篇章均 2000-3000 词；短篇整篇 4000-12000 词；去味密度指标按「词/千词」计。
- 英文标点：弯引号（“ ” ‘ ’）、规范省略号（…）、em-dash 有节制使用（每千词 ≤2），不用全角标点。
- 术语首字母：可数名词单数常规大小写；`payoff`、`hook`、`story unit`、`teardown` 小写。
